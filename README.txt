Биология и котики — нервная система, анализаторы и эндокринная система.
Откройте index.html в браузере. Все восемь PDF находятся в папке pdf/.
Четыре лекции транслируются через Kinescope; для их просмотра необходим интернет и соответствующие разрешения доступа.
Чтобы разместить сайт на GitHub Pages, загрузите index.html и папку pdf/ в корень репозитория.
